# How to fix a saved block

This works for blocks of the **current person** only. A closed person cannot be
reopened yet.

## Change a block

1. Pick the block in the block dropdown and click **edit**. The status line shows
   `editing A2`.
2. Change the text, and/or redo the boxes: **clear pending**, then draw them again.
   Draw one more box to add one.
3. Click **save**. To back out instead, click **cancel edit**.

## Delete a block

Pick it in the block dropdown and click **delete**. The file is written at once.

## Fix a closed person

Edit their `person-NNNN.json` by hand; the format is in
[Input and output](../reference/input-and-output.md).

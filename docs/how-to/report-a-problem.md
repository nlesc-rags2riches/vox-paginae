# How to report a problem

Open an issue in this repository's issue tracker. Include:

- the status line text (it holds the book, file name and page), or a screenshot of the
  whole screen;
- what you clicked, in order, and what you expected instead;
- the `person-NNNN.json` involved, if a file looks wrong.

Check [Known issues](../reference/known-issues.md) first. A wish (something missing
rather than broken) is welcome as an issue too.
